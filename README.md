# مجمع أسواق ريادة المستهلك – متجر إلكتروني PWA متكامل

[![PWA](https://img.shields.io/badge/PWA-Enabled-blue)](https://web.dev/progressive-web-apps/)
[![Supabase](https://img.shields.io/badge/Supabase-Backend-green)](https://supabase.com)
[![License](https://img.shields.io/badge/License-MIT-yellow)](LICENSE)

هذا المشروع عبارة عن **متجر إلكتروني تقدمي (PWA)** يعمل كتطبيق ويب حديث، يتميز بالسرعة، الأمان، وإمكانية العمل دون اتصال بالإنترنت. يشمل النظام مساعداً ذكياً، عداد زوار مركزي في قاعدة البيانات، بحثاً غامضاً، وتقارير سلوك المستخدمين المرسلة إلى لوحة التحكم.

---

## 🚀 الميزات الرئيسية

- ✅ **تطبيق PWA كامل** – يمكن تثبيته على الهواتف والحواسيب، ويعمل بدون إنترنت.
- ✅ **Service Worker متقدم** – يخزن الموقع بالكامل على متصفح الزائر للوصول السريع جداً.
- ✅ **عداد زوار مركزي** (Supabase) – يظهر العدد الحقيقي لجميع الزوار، بدون تخزين محلي.
- ✅ **مساعد ذكي (متدرب)** – نافذة دردشة تفاعلية تجيب على الأسئلة، تسجل التفاعلات، وترسل تقارير إلى قاعدة البيانات.
- ✅ **بحث غامض (Fuzzy Search)** – باستخدام Fuse.js، يقدم اقتراحات حتى مع الأخطاء الإملائية.
- ✅ **إخفاء جميع رسائل الخطأ** – لا يرى المستخدم أي رسائل فشل اتصال بقاعدة البيانات.
- ✅ **تخزين مؤقت للصور والملفات** – لتحسين السرعة وتقليل استهلاك البيانات.
- ✅ **لوحة تحكم منفصلة (`admin.html`)** – لإدارة المنتجات، المتاجر، والإعدادات.
- ✅ **تصميم متجاوب بالكامل** – يناسب جميع الأجهزة (هواتف، أجهزة لوحية، حواسيب).

---

## 🛠️ التقنيات المستخدمة

| التقنية | الوصف |
|---------|-------|
| HTML5 / CSS3 / JavaScript (ES6+) | بناء الواجهات والتفاعل |
| Supabase (PostgreSQL) | قاعدة البيانات السحابية (الحساب المجاني) |
| Service Workers | التخزين المؤقت والعمل دون اتصال |
| Fuse.js | البحث الغامض مع اقتراحات فورية |
| CryptoJS / DOMPurify | تشفير وتنظيف الإدخالات (أمان) |
| Font Awesome 6 | أيقونات احترافية |
| Google Fonts (Cairo) | الخط العربي الجميل |
